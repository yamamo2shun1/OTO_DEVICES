# Notes for Windows Users

JUMBLEQ is a USB Audio Class 2.0 class-compliant device and does not require a device-specific driver for standard audio operation on Windows.

The project does not currently provide a dedicated ASIO driver. For applications that require an ASIO interface or lower-latency audio routing, use one of the following third-party options:

- [VB-Audio Matrix](https://vb-audio.com/Matrix/)
- [ASIO4ALL](https://asio4all.org/)
