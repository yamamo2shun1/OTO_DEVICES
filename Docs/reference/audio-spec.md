# Audio Specifications

## I/O and Format

- Analog I/O: 4 inputs, 4 line outputs, and 2 headphone outputs
- USB I/O: 4 inputs and 4 outputs using USB Audio Class 2.0
- USB MIDI: input and output
- Audio format: 24-bit, 48 kHz or 96 kHz

## Line Input

- Input impedance: approximately 25 kΩ
- Test conditions: 1 kHz sine wave, series-resistor method with 10 kΩ

## Line Output

- Nominal output level: -10 dBV (317 mVrms) at LINE OUT 0 dB
- Maximum user output level: 0 dBV / +2.2 dBu (1.0 Vrms) at LINE OUT +10 dB
- Output impedance: approximately 235 Ω
- Test conditions: 1 kHz sine wave, USB input at 0 dBFS, no load

## Headphone Output

- Nominal output level: 281 mVrms into 100 Ω at HP OUT 0 dB
- Maximum output level: 890 mVrms / 7.9 mW into 100 Ω at HP OUT +10 dB
- Output impedance: approximately 9 Ω
- Test conditions: 1 kHz sine wave, 100 Ω load
