## JUMBLEQ Configurator

JUMBLEQの設定変更を行うためのコンフィギュレーター「[JUMBLEQ Configurator](https://github.com/yamamo2shun1/JUMBLEQ/tree/main/Max)」を用意しています。  
JUMBLEQ Configuratorは [Max 9](https://cycling74.com/ja/products/max-9) で作成しており、Windows / macOSで利用可能です（ただし、Max9のインストールが必要）。
