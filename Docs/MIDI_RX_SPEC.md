# JUMBLEQ Firmware MIDI受信仕様

本ドキュメントは、`JUMBLEQ/Appli/Core` 実装に基づくMIDI受信仕様（2026-07時点）をまとめたものです。

## 1. 基本方針

- 受信MIDIは USB-MIDI 経由で処理する
- UI設定変更に使う受信MIDIは **MIDI Ch.15 固定**（1始まり表記）

## 2. Program Change（Host -> Device）

### 2.1 受理条件

- MIDIチャンネルが Ch.15 のときのみ受理する
- Ch.15以外のPCは無視する

### 2.2 PCマップ

| PC番号 | 機能 |
|---:|---|
| 0/1 | Ch.1の入力タイプ（Line / Phono）を切り替える |
| 2/3 | Ch.2の入力タイプ（Line / Phono）を切り替える |
| 4/5/6/7 | XFader Aに入力ソース（Ch.1 / Ch.2 / USB[1/2] / USB[3/4]）のいずれかを割り当てる |
| 8/9/10/11 | XFader Bに入力ソース（Ch.1 / Ch.2 / USB[1/2] / USB[3/4]）のいずれかを割り当てる |
| 12/13/14/15 | Post XFaderに入力ソース（Ch.1 / Ch.2 / USB[1/2] / USB[3/4]）のいずれかを割り当てる |
| 16/17 | Ch.1のDVSモードをオフ・オンする |
| 18/19 | Ch.2のDVSモードをオフ・オンする |
| 20/21 | Returnソース（USB[1/2] / USB[3/4]）を切り替える |
| 22/23/24/25 | HP出力ソース（XF_A / XF_B / THRU / MASTER）を切り替える |
| 26/27 | 磁気スイッチ2をXFader A/Bの補助fade-downに割り当てる |
| 28/29 | 磁気スイッチ3をXFader A/Bの補助fade-downに割り当てる |
| 120/121 | フェーダー・カーブ調整モードをオフ・オンする |
| 122/123 | 磁気スイッチ操作時のMIDI（CC / Note）を切り替える |
| 126 | 現在デバイスに設定されているパラメータをダンプ送信する |
| 127 | 現在設定をEEPROMへ保存する |

備考:
- 磁気スイッチ2/3の補助fade-down割り当てはPC受信時に即時反映される。
- 磁気スイッチ2/3の初期割り当ては、磁気スイッチ2がXFader A、磁気スイッチ3がXFader B。
- `PC127` はルーティング設定、磁気スイッチ2/3の補助fade-down割り当て、XFADEカーブ指数 `A/B` を保存する。
- `PC126` は EEPROM内容の読出しではなく、**現在の動作状態（保存対象パラメータ）**を送信する。

## 3. Control Change（Host -> Device）

### 3.1 受理条件

以下をすべて満たした場合のみ受理する。

- フェーダー・カーブ調整モードオン中
- MIDIチャンネルが Ch.15
- CC番号が対象（20 or 21）

### 3.2 CCマップ

| CC番号 | パラメータ | 値範囲 |
|---:|---|---|
| 20 | `XFADE_CURVE_EXP_A` | 0.5 ～ 50.0 |
| 21 | `XFADE_CURVE_EXP_B` | 0.5 ～ 50.0 |

変換仕様:
- CC値 `0..127` を指数 `0.5..50.0` へ **対数マッピング**する
- 低い指数側/高い指数側の操作感を均すため、線形ではなく対数で変換する

## 4. curve_edit_modeの挙動

- ON/OFFはPCで切り替える（`PC121` ON / `PC120` OFF）
- ON中はメインOLEDにカーブ編集表示を出す
- OFF中は従来のメインOLED表示（各入出力Chのゲイン値表示）
- 自動タイムアウトは無し

## 5. EEPROM保存・起動時復元

- 保存トリガ: `PC127`（Ch.15）
- 保存対象:
  - CH1/CH2入力タイプ
  - XF A/B/POSTアサイン
  - CH1/CH2 DVS有効状態
  - Returnソースアサイン
  - HP出力ソース
  - 磁気スイッチ2/3の補助fade-down割り当て
  - `XFADE_CURVE_EXP_A/B`
- EEPROMレコードバージョン: `0x0006`
- 起動時読込時、`XFADE_CURVE_EXP_A/B` が範囲外なら `0.5..50.0` にクランプして適用する

## 6. 実装メモ

- 実装内チャンネル値は 0始まり（例: `14` = MIDI Ch.15）
- 受信PC/CCのCh.15制限はそれぞれのdispatch関数内で判定している
